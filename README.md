# Handoffs

Turn vague handoff notes into a clear, one-screen card.

When someone passes work to a teammate, the note is often something like "mostly done, some stuff is blocked, you'll see." Handoffs gives the next person what they actually need: what's done, what's stuck, what not to touch, and what to do first.

**Live demo:** https://YOURNAME.github.io/handoffs/

## What it does

- Guided form with four sections: Done, Stuck, Don't touch, and First thing to do
- Shows a messy Slack message next to the clean card it produces
- Flags vague words like "stuff" and "asap" and gives a ghost-proof score
- Copy the card for Slack, copy it as plain text, print it, or share it by link
- Saves past handoffs in your browser

## How to use it

Open `index.html` in any browser. There's nothing to install and no server to run.

## Built with

Plain HTML, CSS, and JavaScript in a single file. Saved handoffs stay in your own browser, and share links carry the whole card inside the link itself.
